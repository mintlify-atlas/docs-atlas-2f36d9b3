---
title: "Generate AI report"
description: "Generate an executive AI report for a clan — for Team Leaders only. Summarizes coder performance, identifies risks, and provides concrete recommendations."
---

This endpoint generates an AI-written analytical report for a clan's Team Leader. The report includes a current-state summary, a risk assessment, concrete recommendations, and a list of action items. The generated report is saved to the `ai_reports` table in the database.

The endpoint is available at two paths:

| Path | Auth required | Role |
|------|--------------|------|
| `POST http://localhost:8000/generate-report` | No | — |
| `POST http://localhost:3000/api/ai/generate-report` | Yes (session cookie) | `tl` |

<Note>
  When calling through the Node.js proxy at `/api/ai/generate-report`, only Team Leaders (`role = tl`) are authorized. The gateway automatically resolves the TL's clan, total coder count, average score, and high-risk count before forwarding the request. You do not need to provide these values yourself when using the Node.js path.
</Note>

---

## Request body

<ParamField body="clan" type="string" required>
  The clan identifier (e.g., `"Turing"`). Used to scope the report and as the report title.
</ParamField>

<ParamField body="tl_id" type="integer" required>
  The ID of the Team Leader requesting the report. Used to associate the report with the TL in `ai_reports`.
</ParamField>

<ParamField body="total_coders" type="integer" required>
  Total number of coders in the clan.
</ParamField>

<ParamField body="average_score" type="float" required>
  The clan's average academic score out of 100.
</ParamField>

<ParamField body="high_risk_count" type="integer" required>
  Number of coders currently flagged as `high` or `critical` risk with unresolved risk flags.
</ParamField>

<ParamField body="top_struggling_topics" type="string[]">
  The most common topics coders are struggling with across the clan. Included in the report's risk section. Defaults to an empty array.
</ParamField>

<ParamField body="soft_skills_summary" type="object">
  Aggregated soft skills averages for the clan (e.g., `{ "autonomy": 3.2, "teamwork": 4.1 }`). Included in the report when provided. Defaults to an empty object.
</ParamField>

---

## Example request

```json
{
  "clan": "Turing",
  "tl_id": 7,
  "total_coders": 12,
  "average_score": 61.4,
  "high_risk_count": 3,
  "top_struggling_topics": ["Subqueries", "Normalization"],
  "soft_skills_summary": {
    "autonomy": 3.1,
    "time_management": 2.8,
    "problem_solving": 3.5,
    "communication": 3.9,
    "teamwork": 4.2
  }
}
```

---

## Responses

<ResponseField name="success" type="boolean">
  `true` when the report was generated and saved successfully.
</ResponseField>

<ResponseField name="report" type="object">
  The AI-generated report.

  <Expandable title="properties">
    <ResponseField name="report_title" type="string">
      Auto-generated title in the format `"Clan {clan} — Performance Report"`.
    </ResponseField>
    <ResponseField name="generated_date" type="string">
      Human-readable date the report was generated (e.g., `"March 15, 2026"`).
    </ResponseField>
    <ResponseField name="risk_level" type="string">
      Overall clan risk level: `"low"`, `"medium"`, `"high"`, or `"critical"`.
    </ResponseField>
    <ResponseField name="summary" type="string">
      A paragraph describing the clan's current performance state.
    </ResponseField>
    <ResponseField name="risks" type="string">
      A paragraph identifying the main risks and concerns.
    </ResponseField>
    <ResponseField name="recommendations" type="string">
      A paragraph describing what the TL should do.
    </ResponseField>
    <ResponseField name="action_items" type="string[]">
      A list of 3–5 concrete action items for the TL.
    </ResponseField>
  </Expandable>
</ResponseField>

---

## 200 — report generated

```json
{
  "success": true,
  "report": {
    "report_title": "Clan Turing — Performance Report",
    "generated_date": "March 15, 2026",
    "risk_level": "high",
    "summary": "Clan Turing currently has 12 active coders with an average score of 61.4/100. Three coders are flagged as high or critical risk, and the clan shows significant difficulty with subqueries and normalization.",
    "risks": "The 25% high-risk rate combined with below-average scores in time management (2.8/5) suggests coders are struggling to keep pace. Without intervention, these coders risk falling behind before the module assessment.",
    "recommendations": "Schedule individual check-ins with the 3 high-risk coders this week. Focus group sessions on subqueries and normalization would benefit the broader clan.",
    "action_items": [
      "Schedule 1:1 check-ins with the 3 high-risk coders by end of week.",
      "Run a 45-minute group session on SQL subqueries.",
      "Share the normalization cheat sheet resource with the full clan.",
      "Review and update risk flags after check-ins."
    ]
  }
}
```

## 400 — TL has no clan assigned

Returned by the Node.js proxy when the authenticated TL does not have a clan assigned in the database.

```json
{
  "error": "TL has no clan assigned"
}
```

## 500 — LLM returned invalid JSON

```json
{
  "detail": "AI returned invalid JSON"
}
```
