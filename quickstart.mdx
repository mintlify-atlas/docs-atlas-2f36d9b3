Kairo requires three services running simultaneously: the Node.js API Gateway, the Python AI microservice, and a PostgreSQL database (via Supabase). This guide walks you through each.

## Prerequisites

Before you start, make sure you have the following installed:

- **Node.js 18+** — [nodejs.org](https://nodejs.org)
- **Python 3.11+** — [python.org](https://python.org)
- **A Supabase account** — [supabase.com](https://supabase.com) (free tier works)
- **VS Code with the Live Server extension** (recommended for the frontend)

## Setup

<Steps>
  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/Riwi-Project-C6/Learning-Platform.git
    cd Learning-Platform
    ```
  </Step>

  <Step title="Configure the Node.js backend">
    Create a `.env` file inside `backend-node/`:

    ```env
    # SERVER CONFIGURATION
    PORT=3000
    NODE_ENV=development

    # SECURITY & SESSIONS
    SESSION_SECRET=your_session_secret

    # DATABASE (POSTGRESQL - SUPABASE)
    DB_HOST=your_host
    DB_PORT=5432
    DB_NAME=your_name
    DB_USER=postgres.your_user
    DB_PASSWORD=your_password
    DATABASE_URL=your_database_url

    # SUPABASE CONFIG
    SUPABASE_URL=your_supabase_url
    SUPABASE_ANON_KEY=your_anon_key

    # FRONTEND CONNECTION
    FRONTEND_URL=http://127.0.0.1:5500/frontend

    # PYTHON CONNECTION
    PYTHON_API_URL=http://localhost:8000

    # SOCIAL AUTH - GITHUB
    GITHUB_CLIENT_ID=your_client
    GITHUB_CLIENT_SECRET=your_client_secret

    # SOCIAL AUTH - GOOGLE
    GOOGLE_CLIENT_ID=your_client
    GOOGLE_CLIENT_SECRET=your_client_secret

    # AUTHENTICATION SMTP
    SMTP_HOST=smtp.gmail.com
    SMTP_PORT=465
    SMTP_SECURE=true
    SMTP_USER=your_email
    SMTP_PASS=your_app_password
    SMTP_FROM="Kairo <your_email>"

    # API KEY AI
    RIWI_IA_KEY=your_ia_key
    ```

    <Warning>
      `FRONTEND_URL` must exactly match the origin where your frontend is hosted. In development, use `http://127.0.0.1:5500/frontend`. If there is a mismatch, the browser will receive a CORS error and all API calls will fail.
    </Warning>

    <Note>
      Set `SESSION_SECRET` to a long, random string. In development, the server falls back to `dev_secret_fallback`, but you should always set this explicitly. Social auth (GitHub, Google) is optional — if you omit those keys, those OAuth providers are simply disabled at startup.
    </Note>
  </Step>

  <Step title="Configure the Python backend">
    Create a `.env` file inside `backend-python/`:

    ```env
    # PYTHON CONFIGURATION
    PORT=8000
    ENV=development

    # OPENAI-COMPATIBLE API (Groq)
    OPENAI_API_KEY=your_api_key

    # MODEL IA
    MODEL_NAME=your_model

    # SUPABASE CONFIG
    SUPABASE_URL=your_supabase_url
    SUPABASE_SERVICE_KEY=your_service_key

    # BACKEND NODE PORT
    NODE_URL=http://localhost:3000

    # FRONTEND PORT
    FRONTEND_URL=http://localhost:5500
    ```

    <Note>
      `OPENAI_API_KEY` is your Groq API key. The Python service uses OpenAI-compatible endpoints. Get a Groq key at [console.groq.com](https://console.groq.com). Set `MODEL_NAME` to a Groq-supported model such as `llama-3.3-70b-versatile`.
    </Note>
  </Step>

  <Step title="Start the Node.js backend">
    Open a terminal, navigate to `backend-node/`, and run:

    ```bash
    npm install
    npm run dev
    ```

    You should see this output when the server is ready:

    ```
    ------------------------------------------------------------
    🚀 KAIRO API GATEWAY STARTED SUCCESSFULLY
    ------------------------------------------------------------
    📡 URL      : http://localhost:3000
    🌐 Origins  : http://localhost:5500
    🛠️  ENV      : development
    ------------------------------------------------------------
    ```
  </Step>

  <Step title="Start the Python AI backend">
    Open a second terminal and navigate to `backend-python/`. Set up a virtual environment and install dependencies:

    <CodeGroup>

    ```bash Linux / macOS
    python3 -m venv env
    source env/bin/activate
    pip install -r requirements.txt
    uvicorn main:app --host 0.0.0.0 --port 8000 --reload
    ```

    ```powershell Windows
    python -m venv env
    env\Scripts\Activate.ps1
    pip install -r requirements.txt
    uvicorn main:app --host 0.0.0.0 --port 8000 --reload
    ```

    </CodeGroup>

    Wait for the service to finish loading embeddings. You should see:

    ```
    ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
      Kairo AI Service v2.3.0  |  starting up
    ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
    INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)
    ```

    <Note>
      The startup log also shows `INFO: Supabase client initialized` once the database connection is confirmed. If you see an error here, double-check `SUPABASE_URL` and `SUPABASE_SERVICE_KEY` in `backend-python/.env`.
    </Note>
  </Step>

  <Step title="Open the frontend">
    Open a third terminal and serve the `frontend/` directory on port 5500.

    <CodeGroup>

    ```bash VS Code Live Server
    # In VS Code, right-click frontend/src/views/auth/login.html
    # and select "Open with Live Server"
    # It starts at http://127.0.0.1:5500 by default
    ```

    ```bash npx serve
    npx serve frontend -p 5500
    ```

    </CodeGroup>

    <Warning>
      The frontend must be served from port 5500. Loading HTML files directly from the filesystem (`file://`) will cause all authenticated API calls to fail because the browser won't send cookies with cross-origin requests.
    </Warning>
  </Step>
</Steps>

## Verify everything is working

With all three services running, confirm the system is healthy:

| Check | Expected result |
|---|---|
| `GET http://localhost:3000/api/health` | `{ "status": "active", "database": { "connected": true } }` |
| `GET http://localhost:8000/health` | `{ "status": "online", "service": "Kairo AI Engine" }` |
| `GET http://localhost:8000/` | `{ "message": "Kairo AI Microservice — online" }` |
| Open `http://127.0.0.1:5500` in the browser | Login page loads without console errors |
